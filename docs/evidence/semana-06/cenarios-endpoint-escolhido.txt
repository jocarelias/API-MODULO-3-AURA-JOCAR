4. COMPORTAMENTO INTERESSANTE: VALIDACAO DE UUID NO CLIENTE
===============================================================================
O parametro assessmentId esta declarado como `format: uuid`. O Swagger UI
valida isso no proprio cliente e NAO envia o pedido quando o valor e invalido:

  assessmentId = "abc"
  -> "Please correct the following validation errors and try again."
     "For 'assessmentId': Value must be a Guid."
  -> nenhum pedido HTTP chega a ser feito (captura 09)

Para clientes que nao pre-validam (curl, Postman, supertest) a API responde
HTTP 400 VALIDATION_ERROR. As duas behaviours sao correctas e complementares.
Validacao completa do parametro contra a API real:

  vazio /grades                        -> 400 VALIDATION_ERROR
  abc                                  -> 400 VALIDATION_ERROR
  12345                                -> 400 VALIDATION_ERROR
  %20                                  -> 400 VALIDATION_ERROR
  23aad7d5d38340ea89e1bbb89fb258ae      -> 400 VALIDATION_ERROR  (sem hifens)
  aaaaaaaa-aaaa-aaaa-aaaa-aaaaaaaaaaaa  -> 404 NOT_FOUND  (formato valido)
  00000000-0000-0000-0000-000000000001  -> 404 NOT_FOUND
